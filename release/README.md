# 蓝色大肥鱼 · 0.4.0 Windows 一键安装版

0.4.0 调整了蓝色大肥鱼的本地模型吐字风格。她现在会用更加阳光、热情、灵活可爱的方式陪伴主人，说话时少女感更明显，也会根据眼前的内容组织不同的表达，让每次气泡都更像一只正在桌面上生活的小鱼娘。

更新后，大肥鱼启动和关闭时会主动向主人问候。启动时，她会根据系统时间说出合适的欢迎词，并配合行礼动画向主人请安；关闭时，她会说“主人再见~鱼鱼喜欢主人哦”，再完成告别动作。另外，本次还修复了一些使用中的故障，并完善了一些功能细节。

本版本安装包会安装完整的桌宠程序、动画资源和本地运行环境。运行蓝色大肥鱼需要在安装过程中准备本地模型，已有模型在更新时可以继续使用。Vision版由于性能问题，自本版本起不再同步更新。

本版本提供 `BigBlueFish-v0.4.0-OCR-Setup.exe` 安装器。双击安装器后按提示完成安装，安装器会配置桌宠程序、动画资源和运行环境，并在需要时下载本地模型。更新时选择原安装目录即可保留已有设置和已经核验过的模型。

对应的 `.sha256` 文件提供安装器的 SHA-256 校验值。完整功能规格见 [AGENT_FUNCTIONAL_SPEC.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.4.0/docs/AGENT_FUNCTIONAL_SPEC.md)，完整更新记录见 [CHANGELOG.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.4.0/CHANGELOG.md)。
