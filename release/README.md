# 蓝色大肥鱼 · Windows 发布版

适用于 Windows 10 / 11 x64。发布包包含 .NET 10 运行时、桌宠动画和 llama.cpp Vulkan / CPU 推理运行时，不需要先安装开发 SDK。

1. 将 ZIP 完整解压到可写目录。
2. 在此目录打开 PowerShell，运行 `./Setup-Model.ps1` 下载并校验模型（约 2.7 GB）。也可以运行 `./Setup-Model.ps1 -ModelFile "已有模型的完整路径"`，使用同一型号的现有文件。
3. 双击 `VPet-Simulator.Windows.exe`。没有模型时，动画和设置仍可使用，模型播报暂不可用。
4. 右键桌宠，选择“设置”“天气”或“吐字测试”。测试实际调用本地模型，沿用当前显卡 / CPU 配置，生成结果通过正常说话的同一条逐字显示路径输出。天气也以文字气泡播报，没有语音合成。

文字约每秒 28 个字符，按 Unicode 组合字符显示，避免拆开表情或组合字符。气泡从一开始就预留完整内容的大小，不会在旧的小窗口里裁掉后半句。驻留时间从完整显示后开始；手动关闭会立即停止当前吐字。右下角托盘菜单可显示、隐藏或退出桌宠。

设置中可以选择省、市、县区；默认安徽省 / 合肥市 / 蜀山区，可以随时修改。天气使用区县中心附近的 Open-Meteo 天气估算，不代表用户具体街道的实测情况。数据源中部分台湾地区没有坐标，会明确提示暂不可查询，不会改用其他城市天气。

“拔电时暂停并卸载模型”默认开启。关闭后，电池供电时也允许加载、驻留和生成；关闭“启用本地大模型”仍会停止模型。进入系统睡眠或退出桌宠会停止模型进程。

模型在本地运行。自动获取天气与科技新闻可以关闭；主动点击“天气”仍会查询所选地点并交给本地模型生成文本。天气与 RSS 查询需要联网。

配置文件、天气 / 新闻缓存和运行状态位于解压目录。请从托盘退出已有桌宠再启动另一份。

发布文件和模型的许可见 `THIRD-PARTY.md`、`LICENSE` 和 `licenses/`。这是一份基于 VPet 的非官方定制桌宠。

此仓库的 `release/` 保存本地生成的发布包。ZIP、二进制和校验文件不提交进 Git，发布时可把 ZIP 与 `.sha256` 作为 GitHub Release 附件上传。
