# 蓝色大肥鱼 · 1.1.2

本次更新修复了3个故障。

Windows 标准版下载 `BigBlueFish-v1.1.2-OCR-Setup.exe`，无ACP版下载 `BigBlueFish-v1.1.2-Safe-OCR-Setup.exe`；Ubuntu／Debian x64 标准版下载 `BigBlueFish-v1.1.2-Linux-x64.deb`，无ACP版下载 `BigBlueFish-v1.1.2-Safe-Linux-x64.deb`。文件名中的 `Safe` 对应无ACP版，各安装包均提供配套 `.sha256` 校验文件。已安装的用户可以在设置中检查更新直接升级，也可以手动运行新版安装器；Windows 上选择原安装目录即可保留模型与设置。

连接方式与适配列表见 [连接本机 CLI Harness](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.2/docs/ACP.md)，内部工具参数见 [内部工具参考](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.2/docs/MCP.md)，完整行为见 [功能规格](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.2/docs/AGENT_FUNCTIONAL_SPEC.md)，版本变化见 [更新日志](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.2/CHANGELOG.md)。
