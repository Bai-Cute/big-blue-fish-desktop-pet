# 蓝色大肥鱼 · 1.1.3-beta.1

本次更新修复了一些 Bug，并加入了鱼鱼聊天记录的滚动查看功能。主人现在可以在对话输入框中向上滚动，翻看之前和鱼鱼说过的话。

本次还新增了由贡献者 **YamaFuso** 开发的 **[macOS 移植版](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.3-beta.1/docs/MACOS.md)**，非常感谢他为蓝色大肥鱼适配新平台所付出的努力！Mac 移植版未经仓库维护者本人亲测，欢迎使用 Mac 的主人体验并反馈使用情况。

**本版本为 Beta 测试版本，暂时不能保证稳定性。**
