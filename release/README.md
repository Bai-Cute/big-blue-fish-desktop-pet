# 蓝色大肥鱼 · 0.3.1 Windows 一键安装版

0.3.1 在 0.3.0 的基础上，重点修正了安装和卸载体验。蓝色大肥鱼安装时会在 Windows 中规范注册，安装后可以在开始菜单找到并启动，也可以通过 Windows“已安装的应用”进行卸载。

本次加入了规范的卸载器，开始菜单中也提供卸载入口。卸载界面提供“保留模型和设置”复选框，默认不勾选，可以手动勾选保留，方便以后重新安装；界面布局已调整，文字、选项和按钮能够完整显示。

同时修复了数据保存在安装目录、但未为普通用户授予写入权限的 bug。安装器现在会为蓝色大肥鱼自己的安装子文件夹配置访问权限，让设置和数据能够正常保存，权限配置仅作用于蓝色大肥鱼的子文件夹。模型加载失败或本地推理服务失效后的恢复问题也已修复，后续请求可以重新启动模型，无需重启桌宠。

大肥鱼现在会每小时访问并缓存最近的天气信息，天气播报使用最近且不超过六小时的资料，减轻对当前互联网连接可靠性的依赖。

由于性能问题，0.3.1 是视觉版的最后一个维护版本。从下一版本起，不再维护视觉版更新，仅发布 OCR 版。

本次仍提供两种安装器：下载 `BigBlueFish-v0.3.1-Vision-Setup.exe` 安装视觉版，或下载 `BigBlueFish-v0.3.1-OCR-Setup.exe` 安装 OCR 版。视觉版直接读取当前窗口截图；OCR 版使用本地文字识别，把界面文字按位置整理后交给模型。两版沿用 0.3.0 的动作、表情、天气、科技新闻和设置功能。

双击安装器后按提示安装，安装器会自动配置桌宠程序、动画资源和运行环境，并从 Hugging Face 下载约 2.7 GB 的本地模型；视觉版还会下载与模型匹配的视觉投影组件。安装器会显示下载来源和状态，完成后创建快捷方式并启动桌宠。

更新前先退出正在运行的桌宠，再运行安装器并选择原安装目录。安装器会保留已有设置，并校验已有模型；校验通过的模型可以继续使用。切换视觉版与 OCR 版时，也可以使用同一安装目录。

对应的 `.sha256` 文件提供安装器的 SHA-256 校验值。完整更新记录见 [CHANGELOG.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.3.1/CHANGELOG.md)。
