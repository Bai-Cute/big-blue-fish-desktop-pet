# 蓝色大肥鱼 · 1.1.1

鱼鱼的整套106种动画升级至1280×720、60帧/秒，放大后更加清晰，动作也更加流畅。我们还重做了动画播放管线，降低播放时的系统资源占用，让鱼鱼更轻快地陪伴主人。

天气地点现在支持全球选择，主人可以先选择国家，再选择当地的行政区和城市，让鱼鱼关心更多地方的天气。

设置中新增日志控制台，实时保留最近32768条排障记录，并支持保存为 TXT，方便主人反馈问题。

本次还优化了吐字流程，并修复了一些 bug。

Windows 标准版下载 `BigBlueFish-v1.1.1-OCR-Setup.exe`，无ACP版下载 `BigBlueFish-v1.1.1-Safe-OCR-Setup.exe`；Ubuntu／Debian x64 标准版下载 `BigBlueFish-v1.1.1-Linux-x64.deb`，无ACP版下载 `BigBlueFish-v1.1.1-Safe-Linux-x64.deb`。文件名中的 `Safe` 对应无ACP版，各安装包均提供配套 `.sha256` 校验文件。已安装的用户可以在设置中检查更新直接升级，也可以手动运行新版安装器；Windows 上选择原安装目录即可保留模型与设置。

连接方式与适配列表见 [连接本机 CLI Harness](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.1/docs/ACP.md)，内部工具参数见 [内部工具参考](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.1/docs/MCP.md)，完整行为见 [功能规格](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.1/docs/AGENT_FUNCTIONAL_SPEC.md)，版本变化见 [更新日志](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v1.1.1/CHANGELOG.md)。
