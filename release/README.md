# 蓝色大肥鱼 · 0.3.0 Windows 一键安装版

蓝色大肥鱼提供视觉版与 OCR 版两种安装器。视觉版直接读取当前窗口截图，结合画面和文字理解内容；OCR 版使用本地文字识别，把界面文字按位置整理后交给模型。两版都使用同一个 4B 本地模型，拥有相同的角色动作、天气、科技新闻和设置功能，可以选择自己更喜欢的一版。

下载 `BigBlueFish-v0.3.0-Vision-Setup.exe` 安装视觉版，或下载 `BigBlueFish-v0.3.0-OCR-Setup.exe` 安装 OCR 版。双击后按提示安装，安装器会自动配置桌宠程序、动画资源和运行环境，并从 Hugging Face 下载约 2.7 GB 的本地模型；视觉版还会下载与模型匹配的视觉投影组件。安装器会显示下载来源和状态，完成后创建快捷方式并启动桌宠。

0.3.0 内置超过 100 种动作和表情，重新整理了待机、点击、定时事件、节日、季节、饭点和夜间休息等触发逻辑。桌宠启动和关闭时会温柔行礼，动作在没有被新交互打断时会自然播放完整，定时动作的间隔可以在设置中调整。更多根据时间、日期、季节和交互组合出的可爱动作，等主人在日常使用中慢慢发现。

更新前先退出正在运行的桌宠，再运行安装器并选择原安装目录。安装器会保留已有设置，并校验已有模型；校验通过的模型可以继续使用。切换视觉版与 OCR 版时，也可以使用同一安装目录。

对应的 `.sha256` 文件提供安装器的 SHA-256 校验值。完整更新记录见 [CHANGELOG.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.3.0/CHANGELOG.md)。
