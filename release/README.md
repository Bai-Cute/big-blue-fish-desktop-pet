# 蓝色大肥鱼 · 1.1.4

本次更新为 Windows 加入了“截屏时隐藏大肥鱼”功能。主人可以在设置中开启，让鱼鱼、文字气泡和对话输入框在截屏与录屏中隐藏，桌面上的陪伴照常进行。鼠标停在鱼鱼身上时，现在也会显示张开的手掌，按住和拖动时则会握紧。

鱼鱼现在可以直接连接 DeepSeek Harness 桌面版，无需另行安装 dsh 命令行。供电设置也改为了“拔电时暂停鱼鱼的AI功能”，同时照顾内置模型和 Agent：拔电后暂停 AI 功能，关闭鱼鱼自己启动的 Agent 进程，插回电源后恢复。

我们压缩了全部高清动画，在保留 1280×720、60 帧/秒和透明效果的同时，将高清动画文件的总体积减少了约 55%，安装包也随之缩小。此外，本次改进了更新器的下载校验流程，改善了启动兼容性，并修复了一些 Bug。

macOS 继续提供原来的 1.1.3 安装包：[标准版](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/releases/download/v1.1.3/BigBlueFish-v1.1.3-macOS-arm64.dmg)、[无ACP版](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/releases/download/v1.1.3/BigBlueFish-v1.1.3-Safe-macOS-arm64.dmg)。
