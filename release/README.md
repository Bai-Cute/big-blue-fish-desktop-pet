# 蓝色大肥鱼 · 0.4.2 Windows 一键安装版

调整了新闻功能，使之更可用，并做了一些美术优化。

本版本安装包会安装完整的桌宠程序、动画资源和本地运行环境。运行蓝色大肥鱼需要在安装过程中准备本地模型，已有模型在更新时可以继续使用。

本版本提供 `BigBlueFish-v0.4.2-OCR-Setup.exe` 安装器。双击安装器后按提示完成安装，安装器会配置桌宠程序、动画资源和运行环境，并在需要时下载本地模型。更新时选择原安装目录即可保留已有设置和已经核验过的模型。

对应的 `.sha256` 文件提供安装器的 SHA-256 校验值。完整功能规格见 [AGENT_FUNCTIONAL_SPEC.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.4.2/docs/AGENT_FUNCTIONAL_SPEC.md)，完整更新记录见 [CHANGELOG.md](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/blob/v0.4.2/CHANGELOG.md)。
