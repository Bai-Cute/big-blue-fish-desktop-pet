# 蓝色大肥鱼桌宠 / Big Blue Fish Desktop Pet

一只内置 4B 本地大模型的 Windows AI 桌面宠物。蓝色大肥鱼会读懂当前窗口里的画面或文字，结合主人正在做的事情、天气和科技新闻，以女仆人设弹出温柔又俏皮的文字气泡，陪主人工作与休息。提供视觉版和 OCR 版两种一键安装器，自动配置模型与运行环境。

蓝色大肥鱼是一只可爱的 Windows 桌宠软件，形象来自“蓝色大肥鱼”的二创设定。她有一身柔软的蓝色长发和小小的鲸鱼尾巴，穿着整洁的女仆裙，头顶的发饰、围裙和轻轻摇动的尾巴，让她看起来像一位住进电脑里的小女仆。她会安静地待在桌面边缘，也会在主人忙碌时探头、挥手、伸展或开心地蹦起来，用小小的动作陪着主人工作。

她不是一个冷冰冰的工具，而是一只会在桌面上生活的蓝色大肥鱼。她会记得自己的女仆身份，喜欢用亲近、温柔又有一点俏皮的语气向主人问候。看见主人在给蓝色大肥鱼写代码，她会摇摇小尾巴，为认真工作的主人加油；看见主人和朋友约明天吃饭，她也会忍不住对热腾腾的好吃的动一点小心思。天气变冷或工作时间很长时，她会从气泡里送来一句轻轻的关心，让桌面上的陪伴更贴近主人眼前的生活。

蓝色大肥鱼内置 4B 本地模型，在电脑上读取当前前台窗口的可见内容，并联网获取天气和科技新闻，再以女仆人设组织成一小段新的话。她可以围绕正在阅读的文章、正在编写的文档或代码，以及聊天中提到的话题，温柔可爱地表达对主人的关心。模型只进行单次输出，没有对话记忆，也不能与用户连续聊天。用户在电脑上的行为不会被上传到云端，也不会被保存到本地。

蓝色大肥鱼内置超过 100 种不同的动作和表情，目前已经准备了 106 条动作规则。每一种动作表情都经过细致设计，既保持蓝色大肥鱼轻松、柔软又灵活可爱的气质，也会根据主人当下的使用情境自然出现。她平时会在桌面上安静地休息、哼歌、伸展、挥手、害羞或开心地蹦跳；主人点击她时，会从多种回应动作中随机选出不同的反应；经过一段时间后，还会触发吃饭、玩耍、工作陪伴、季节活动和节日动作等小事件。许多节日前后会加入专属的动作表情，三餐时间附近会明显提高用餐相关动作的出现机会，夜间休息时段也会改变待机和睡觉动作的权重。动作在没有被新的交互打断时会自然播放完整，再进入下一段陪伴，让桌面上的蓝色大肥鱼像是真的住在这里一样，时不时给主人带来一点可爱的小惊喜。笔记本电脑离开电源时，桌宠可以自动停止模型推理并将模型移出内存，以改善续航；这个行为也可以在设置中调整。离电暂停期间点击天气或吐字测试，她会在气泡里提醒主人可以到设置里调节。

## 识别方式

蓝色大肥鱼提供视觉和 OCR 两种识别方式，两者使用同一个 4B 本地模型，也拥有相同的角色、动作、天气、新闻和设置功能。

视觉版把当前前台窗口的截图直接交给多模态模型，让大肥鱼结合界面画面和可见文字理解眼前的内容。OCR 版先使用 Windows 的本地文字识别组件读取窗口，再按文字在界面中的位置整理输入，交给模型理解文章、文档、代码和聊天话题。

两种方式都围绕当前窗口中的内容表达关心。主人停留在桌面、主页或新标签页时，她也会围绕眼前的界面自然地问候、撒娇或碎碎念。可以根据自己的电脑和使用习惯，选择更喜欢的一版。

## 一键安装

普通用户请从 [GitHub Releases](https://github.com/Bai-Cute/big-blue-fish-desktop-pet/releases/latest) 下载喜欢的识别版本：

`BigBlueFish-v0.3.1-Vision-Setup.exe` 为视觉版，直接读取当前窗口的画面；`BigBlueFish-v0.3.1-OCR-Setup.exe` 为 OCR 版，识别并整理当前窗口中的文字。

双击安装器即可开始部署。安装器会把桌宠程序、动画资源、.NET 运行时和本地推理运行时安装到电脑中，并从 Hugging Face 的固定来源下载约 2.7 GB 的 4B 模型。视觉版还会下载约 640 MB 的视觉投影组件，让模型能够读取窗口图片。下载文件会经过 SHA-256 校验，安装完成后创建快捷方式并启动桌宠。

更新时先退出正在运行的桌宠，再运行安装器并选择原安装目录。安装器会保留已有设置，并校验已有模型；校验通过的模型可以继续使用。切换识别版本时，也可以安装到同一目录，由安装器更新对应的程序文件。

模型下载源是：

```text
https://huggingface.co/Biomanticus/Qwen3.5-4B-heretic-gguf/resolve/b63ff4662e4863cfa005c9cd8ed34b87ed44b7e1/Qwen3.5-4B-heretic-f16_Q4_K_M.gguf?download=true
```

模型文件名为 `Qwen3.5-4B-heretic-Q4_K_M.gguf`，SHA-256 为：

```text
8485535a36c9f333574d08b650ad698ac02ec30752bd9cd87e493a3b7531bee1
```

视觉投影组件使用与该模型匹配的 `Qwen3.5-4B-heretic.mmproj-f16.gguf`，安装器会从固定版本的 Hugging Face 下载并校验它，不需要用户单独配置。其来源是：

## 从仓库部署

仓库面向开发者和维护者，包含源码、动画资源、地区数据、构建脚本、发布脚本、测试程序、依赖锁文件和许可文件。仓库不包含模型权重、运行时二进制、用户设置、缓存、日志或本地发布包。

在 Windows x64 环境中安装 .NET 10 SDK 后，可以从仓库根目录执行：

```powershell
# OCR 版
./code/build.ps1 -Locked -InputMode Ocr

# 视觉版
./code/build.ps1 -Locked -InputMode Vision
```

构建一键安装器需要一个已经核对过的 llama.cpp 运行时目录：

```powershell
# OCR 版安装器
./tools/Build-Installer.ps1 -InputMode Ocr -RuntimeDirectory "运行时目录"

# 视觉版安装器
./tools/Build-Installer.ps1 -InputMode Vision -RuntimeDirectory "运行时目录"
```

安装器自身携带桌宠程序和运行时；模型由安装器在安装过程中从固定来源下载，不会被写入 Git 仓库。

项目版本统一记录在根目录的 `Version.props`，当前为 **0.3.1**。视觉版与 OCR 版使用相同的项目版本，程序、应用组件和安装器均从这份配置生成版本信息。两种识别方式共享同一份桌宠源码，通过构建参数选择输入方式。

## 天气、科技新闻和桌宠行为

蓝色大肥鱼支持省、市、县区三级天气地点选择。天气内容根据用户选择的地区读取，再由本地模型组织成女仆人设的聊天气泡。桌宠也会分享科技新闻，并结合当前窗口中看到的画面或文字，围绕主人正在做的事情表达关心，让天气、新闻和桌面陪伴自然地连在一起。

大肥鱼的行为主要分为待机、点击和定时触发三类。待机是她平时最常用的状态，桌面上会在呼吸休闲、悠闲哼歌等动作之间随机轮换；到了夜间，待机表现会发生变化，并可能进入原地小憩、沉眠等更安静的动作。每段动作在没有被新的交互打断时会自然播放完整，再进入下一段陪伴。

点击大肥鱼时，会从 5 种点击回应动作中按照不同权重随机选择一种。她可能元气地挥手、开心地跃动、害羞地回应，也可能露出傲娇或怕痒的反应，因此同样一次点击也不会总是得到完全相同的回答。拖动桌宠时则使用独立的拖拽反馈动作，让她对主人的操作做出相应回应。

定时触发会在待机一段时间后，从大量事件动作中随机挑选下一件小事。春节、元宵节、情人节、520、七夕、端午、中秋等节日前后，蓝色大肥鱼会把相应的节日动作加入事件选择，部分节日动作还会随着日期接近而逐渐提高出现机会。圣诞、万圣节等其他时令主题也会按照日历进入相应的动作安排。

三餐时间前后会出现专属的用餐动作，早餐、午餐和晚餐各有自己的动作倾向，饭点附近相关动作的出现权重会明显改变。夜间进入休息和就寝时段后，睡觉、打瞌睡以及其他安静动作会更容易出现。部分动作属于季节专属内容，在特定季节里会采用不同的出现逻辑，让同一个桌面宠物随着时间变化呈现不同的生活气息。

大肥鱼启动时会温柔地向主人行礼，关闭时也会用同样的礼仪动作告别。除此之外，她还安排了玩耍、碎碎念、伸展、庆祝、季节活动和其他小事件，并通过不同的时间、日期、季节、饭点、交互方式和动作权重组合出更细致的触发效果。她还藏着许多不会提前剧透的小心思：有些动作会根据前后行为、时段和当天的生活节奏悄悄接上，有些只在特定日子短暂出现，更多可爱的组合则等着主人在日常陪伴里慢慢发现。主人可以在设置中调整定时动作的触发间隔，让桌面的陪伴节奏更符合自己的习惯。

模型准备说话时，角色头旁会出现小小的转圈动画；生成的文字会随着模型输出逐步显示在气泡里。右键菜单中的吐字测试与自动说话使用相同的生成和显示流程。

## 项目结构

`code/` 保存 C#、XAML、动画、地区数据、测试程序和依赖锁文件；`installer/` 保存一键安装器的源码；`tools/` 保存构建发布与模型配置工具；`docs/` 保存 README 截图、透明展示图和动作动图；`release/` 保存发布说明模板。
