# 蓝色大肥鱼 0.1.0 行为规格

## 运行、窗口与生命周期

程序在 Windows x64 桌面运行。主程序为 `VPet-Simulator.Windows.exe`，启动后把工作目录设为程序所在目录，读取设置并创建透明、无边框、置顶的角色窗口。角色窗口不显示任务栏按钮，不因角色点击而取得键盘焦点。对话气泡是跟随角色的独立透明窗口，同样置顶、不激活、不显示任务栏按钮。

同一登录会话使用 `Local\BlueWhaleCompanion` 互斥量限制单实例；已有实例时，新启动的进程直接退出，不创建第二只桌宠。程序打开 `companion.lock` 并持有到退出。

初始化后，主调度每40毫秒执行一次。自动说话首次到期时间是启动后45秒；是否真正生成还受模型、供电、窗口可见性、设置窗口和键鼠空闲条件约束。模型允许运行时可在首次说话之前预加载，不等待用户点击。

默认位置在主显示器工作区右下角；设置中已有 Left、Top 时先恢复，再限制到显示器工作区。显示器配置变化时重新限制位置。位置、缩放和菜单操作不要求模型就绪。

退出时停止调度、取消模型请求、释放模型进程与动画组件、关闭设置和气泡、移除托盘图标、保存设置并释放单实例锁。模型子进程绑定关闭即终止的 Windows Job；宿主退出时子进程随之结束。

## 设置、默认值与保存

| 设置字段 | 默认值 | 行为 |
| --- | --- | --- |
| ModelEnabled | true | 启用本地模型 |
| GpuEnabled | true | 使用GPU推理 |
| PublicInfo | true | 自动天气与科技新闻 |
| ForegroundEnabled | true | 读取当前应用内容 |
| StopModelOnBattery | true | 电池供电时暂停并卸载模型 |
| WeatherRegionCode | 340104 | 安徽省 · 合肥市 · 蜀山区 |
| Scale | 1 | 角色大小100%，范围65%–160% |
| SpeechMinMinutes | 8 | 自动说话间隔档位 |
| BubbleDurationIndex | 3 | 吐字完成后驻留30秒 |
| Left / Top | 空 | 无保存位置时使用默认右下角 |

设置存放在安装目录的 `preferences.json`。读取依次尝试主文件与 `preferences.json.bak`，均无法读取或反序列化时使用默认设置。未知字段不影响读取，缺少字段使用其默认值。

保存先写 `preferences.json.tmp`；已有主文件时以原子替换提交，并将上一份主文件留在 `.bak`；首次保存则移动临时文件为主文件。保存包含当前位置。修改设置、关闭设置、完成拖动和退出会触发保存。

角色大小读取时限制到65%–160%，界面以5%为步进。气泡驻留下标限制到0–7。地区必须为已收录的县区级编码，否则使用340104。

## 位置、缩放与气泡排布

角色基准高度是280个 WPF 逻辑像素，乘以 Scale 得到角色显示尺寸。角色大小65%–160%，5%步进。气泡不随角色大小同比例缩放。

贴边计算使用角色的可见身体区域，而不是透明画布。松开拖拽、恢复显示、修改角色大小、显示器或DPI变化时，将身体限制到所在显示器工作区；身体距任一边不足14个逻辑像素时吸附到该边。拖动中的位置跟随鼠标，松开后再限制。

气泡优先位于角色上方，水平朝角色中心对齐；上方空间不足时放在角色下方，最终保留距工作区边缘至少8个逻辑像素。气泡随角色移动、文字变化、窗口大小和DPI变化重新排布。显示器依据角色可见身体中心所在屏幕选择，坐标按当前DPI换算。

气泡内容先按可用宽度测量，单个气泡最大基础宽度为300个逻辑像素，并受当前屏幕工作区限制。较长文字换行，气泡高度受工作区高度限制。关闭按钮只关闭气泡，不关闭桌宠，也不启动新请求。

气泡是圆角矩形，圆角18，基础文字字号15，字体 Microsoft YaHei UI，带独立关闭按钮。

## 点击、拖动、菜单与设置窗口

左键按下时记录鼠标物理坐标和窗口起点并捕获鼠标。移动距离按DPI换算；横向与纵向位移绝对值之和超过4个逻辑像素时确认为拖动。角色位置跟随此次鼠标位移。松开后释放鼠标、限制位置并保存。
松手时有拖动则播放 happy，无拖动则播放 blush，并把下一随机动作排到20秒后。

角色右键菜单包含设置、天气、吐字测试。菜单动作关闭当前菜单后执行。托盘菜单包含显示桌宠、设置、天气、吐字测试、关闭桌宠；双击托盘图标恢复桌宠。开机启动开关读写当前用户Run项中的 BlueWhaleCompanion，开启时保存当前可执行文件的带引号路径，关闭时移除该项。

设置仅创建一个窗口，已有设置窗口时复用并调用激活。设置窗口有任务栏入口，关闭时保存当前设置。

设置为单页滚动窗口，宽460，内容自适应高度。包含模型、GPU、离电暂停、开机启动、公共信息、当前应用感知、省市区、角色大小、说话频率、气泡驻留，以及隐藏、回到右下角和关闭按钮；状态文字每秒刷新。

## 动画与随机移动

角色动画来自 `assets/pet` 下的PNG帧目录，按帧文件名前的数字顺序读取，idle 作为默认动画，其他作为单次动作。角色绘制使用蓝色渲染。动画就绪后写入 `ready.status`；加载失败记录到 `companion-errors.log` 并显示动画加载提示。

启动后12秒第一次随机动作；之后每次抽取18–37秒的整数等待。插电时等概率从 wave、stretch、happy、sit、sit_stretch、eat、music、swim、idle 九项选择；未插电时等概率从 idle、sit、sleep、stretch 四项选择。设置窗口打开、角色隐藏、全屏隐藏、未就绪或拖动时不进入这段动作调度。

执行动作时按单次动画播放，完成后回默认状态。sleep 的动作期限字段为18秒，其余为8秒。这里没有按节日、三餐和季节选择的动作池，也没有启动、关闭的固定问候气泡。

选到 swim，或者电池状态下另一次五分之一抽取命中时，选择以锚点为中心−45至+45逻辑像素的横向目标，先限制目标到工作区，再逐帧向目标移动。速度16个逻辑像素/秒；每次时步最多按0.15秒计算。移动结束清除目标并恢复渲染变换。点击或拖动可覆盖当前动作。

## 自动说话的时间与门控

四档为3–10、8–15、15–22、30–37分钟，默认8–15分钟。持久化字段为下限3、8、15或30，普通说话每次在下限上加0–7的均匀随机整数分钟。配置文件读取时允许下限3–60。

主调度只在角色已就绪、可见、没有拖动、设置窗口未打开、模型启用且供电允许时触发自动说话。模型正在加载或生成、手动天气请求占用时，自动说话等待后续调度。

到期后还要求距最近一次键鼠输入至少8秒且不超过600秒；不满足则把到期时间推迟30秒。手动吐字测试不检查这一空闲条件。

普通请求开始前排定下一次随机说话时间。手动天气结束、恢复显示、供电事件及修改档位时，按保存的下限分钟排定；开启模型时将下一次自动说话排到20秒后。

自动生成返回后还要求距最近一次键鼠输入至少5秒，否则不显示该次结果。自动与测试分别持有请求状态；手动测试不读取当前应用或公共信息，直接调用真实模型的普通生成入口。

## 吐字测试

点击吐字测试后，若用户隐藏了桌宠先恢复显示。模型未启用时显示暂停提示。可运行时显示等待短句提示，注明GPU或CPU，等待已有模型工作最多100秒，然后调用 Generate(false,false)，本轮仅提供时间与“用户正在使用电脑”的一般状态。

成功结果通过实际模型气泡逐字显示，并播放wave动作；空结果显示含模型状态的测试提示。重复测试在 speechTestPending 期间直接返回；测试结束把下一次自动说话排到所选下限分钟后。
模型关闭或离电暂停时，测试使用统一暂停提示；电源策略会隐藏气泡。

## 生成输入、人设与消息结构

模型人设为亲昵活泼的鲸鱼娘，称用户“主人”，结合当前状态表达问候、关心、夸奖、打趣或好奇。普通请求提示以20–65字、1–2个短句表达；人设给出少量口吻演示。天气和新闻分别有独立人设及请求，不混为一个对话场景。

每次消息数组含一条 system 人设与一条 user 本轮资料；不附带前次生成结果或聊天历史。普通资料包含当前系统日期时间，开启应用感知时再加入前台信息，关闭时使用“用户正在使用电脑”。

应用感知只取前台进程名和窗口标题。读取失败、没有窗口标题或当前窗口属于桌宠时，使用对应的一般状态描述，不读取截图、OCR正文或聊天内容。

## 模型进程、推理参数与输出清理

程序启动安装目录下的 `runtime/llama-server.exe`，模型为 `models/Qwen3.5-4B-heretic-Q4_K_M.gguf`，仅监听127.0.0.1，端口从可用本地端口选择。关闭Web界面和模型日志输出，启用模型自己的Jinja聊天模板，关闭思考；请求同时设置 enable_thinking=false。

GPU开关开启时GPU层数99，关闭时0；线程数4，并行槽位1。GPU微批32、CPU微批512，上下文2048。

普通生成和天气生成各有100秒取消期限；预加载有90秒期限。预加载失败后不连续每帧重试，下次允许尝试时间推进两分钟。修改GPU模式先停止当前进程，下次按新配置加载。

已有模型进程仍存活时直接复用。新进程启动后最多轮询120次 /health，每次间隔500毫秒；进程提前退出、供电不允许、取消或始终未就绪时返回相应状态。模型加载失败后仍存活的进程可保留在引用中，后续请求会按存活进程复用条件处理。

推理使用本地 /v1/chat/completions。top_p=0.9；普通请求temperature=0.65，天气和新闻temperature=0.4。天气最多220个输出token，其他最多180。请求非流式，完整收到回复后再开始气泡逐字显示。

输出清理移除成对think标签及其内容；仍有未闭合think标签时返回空文字。空白折叠为空格并去掉首尾引号。没有字母或数字，或同一字符连续至少九次时返回空文字。少于100个Unicode标量值时保留；否则取前98个，在其中最后一个句号、感叹号、问号或全角波浪线位置不早于索引15时截至该标点，否则加省略号。

生成期间 Busy 阻止同一模型对象并发请求；取消、成功和异常的收尾均释放 Busy 和请求取消对象。关闭模型或退出会取消活动请求并终止模型进程；只取消当前生成时不强制卸载一个健康的驻留进程。

## 加载圈、吐字与驻留

非流式结果统一按每秒28个文本字素显示，每25毫秒刷新一次，首个字素立即出现。使用Unicode组合字符边界，避免把组合字符或代理对拆成半个字。全文用于测量气泡，显示前缀用于逐字呈现。

驻留可选5、10、15、30、60、120、180秒或“直至下一句”，默认30秒；正常模型回复从吐字完成后开始计时。新回复替换旧回复并重置期限。调整驻留档位时，当前可见气泡按新档位重新计时。关闭气泡停止当前逐字动画；流式生成尚未结束时，后续新片段仍可重新显示气泡。

固定通知使用预设文字显示，不调用模型。离电暂停策略会隐藏当前气泡。

## 天气地点、内容与缓存

天气地点为省、市、县区三级联动选择，默认安徽省 · 合肥市 · 蜀山区。切换省重新选择对应市县，切换市重新选择县区，最终县区编码保存到设置。切换县区使旧请求失效并取消正在生成的旧地点结果。

天气源为 Open-Meteo，使用县区中心坐标查询，时区固定Asia/Shanghai、预报一天。输入模型的资料包含完整地点名、观测时间、天气代码对应的中文、气温、体感、相对湿度、风速、当天最高最低温和最高降水概率。未收录坐标的县区不能发起有效天气请求。

天气代码映射：0晴朗，1大部晴朗，2局部多云，3阴天，45/48有雾，51/53/55毛毛雨，56/57冻毛毛雨，61小雨、63中雨、65大雨，66/67冻雨，71小雪、73中雪、75大雪、77雪粒，80小阵雨、81阵雨、82强阵雨，85/86阵雪，95雷雨、96/99雷雨伴冰雹，其余为天气状况未提供。

天气在当前进程内按最近一个地区缓存15分钟。普通说话取该地区有效缓存，无缓存或过期时联网；手动天气强制联网刷新。只有网络成功并完整解析后才替换缓存，天气不保存到磁盘。公共请求HTTP客户端超时12秒。

普通说话开启公共信息时有15%概率附加天气资料，天气资料为空时不附加有效天气事实。手动天气独立于公共信息开关，但要求模型开启且供电允许。

手动天气先显示所选地点的查询通知；已有天气请求时重复点击直接返回。等待模型已有工作最多100秒，再进行真实天气生成。地点改变、模型关闭、隐藏、全屏或退出使旧结果不能作为最终气泡显示；生成失败时手动天气可显示模型状态提示。手动天气结束后重排自动说话时间。

## 科技新闻选择

开启公共信息时，普通说话入口尝试新闻门控。程序启动后先等待两小时，且至少成功生成12次普通非新闻短句；满足条件后每次机会有2%概率预约新闻。每个本地自然日最多预约一次，预约后再次进入两小时静默，并把普通短句计数清零。

预约日期保存到 `news-last-day.txt`，重启仍保留当日限制；普通短句计数和两小时期限不跨进程保存。日期写入失败则不预约。预约先于联网和模型生成，因此后续没取得标题、生成失败或返回略过，也消耗当日预约。

新闻源为 https://www.ithome.com/rss/ ，仅取发布时间不在未来、距当前小于两天的标题。标题长度12–160，去重后最多10条，按源顺序选择首个不同于上次新闻的标题。标题缓存45分钟，失败也要到缓存期限后再取；仅标题进入模型，不取正文。

标题必须包含发布、推出、开源、上线、宣布、支持、更新、正式、获批、发现中的至少一个词；含“某、据传、网传、疑似、曝光、爆料、或将、即将、重磅、震撼、不一样、悬念”中的任一词，或含中英文问号时排除。

本次取到可用标题时只用新闻消息生成，不附加前台活动或天气；没有可用标题时走普通屏幕或时间资料。输出包含“略过”时最终结果为空。完整结果还必须以“主人，看到一条科技消息：”开头，否则最终结果为空。

## 供电、隐藏与模型驻留

默认启用离电暂停策略。只有系统电源状态明确为AC=1才按插电处理；查询失败也按未插电处理。启用策略且未插电时取消请求、终止模型进程，保留动画与设置操作。休眠事件停止模型；供电或恢复事件重新应用策略并重排说话时间。

关闭“启用本地大模型”会停止模型并取消活动请求；已完成生成的气泡继续按自身驻留规则显示，正在生成的流式气泡由请求收尾分支处理。开启后允许预加载，并将下一次自动说话排到20秒后。关闭GPU开关改用CPU，重新启动推理进程。关闭公共信息只停止自动公共信息使用，不等于禁止手动天气。

用户隐藏会取消当前吐字动画和模型请求、隐藏气泡及角色并关闭设置；当前供电允许时只取消生成，不主动卸载健康模型。隐藏和全屏状态检查之前仍执行供电与预加载逻辑，因此隐藏期间允许预加载。显示桌宠会重新显示、限制位置并重排说话时间。

外部前台窗口覆盖其所在显示器整个屏幕矩形时按全屏处理，explorer与桌宠自身排除。进入全屏自动隐藏角色并取消生成；退出全屏且用户未主动隐藏时恢复。用户主动隐藏优先于全屏退出恢复。

离电状态下天气入口显示供电提示，吐字测试显示统一暂停提示；随后调度中的离电策略可隐藏当前气泡。

## 安装、更新与卸载

安装器默认目录为 Windows Program Files 下的“蓝色大肥鱼”子目录，允许用户选择安装目录；浏览文件夹后追加“蓝色大肥鱼”文件夹名。安装器携带桌宠、动画、解码器、本地推理运行时和自包含.NET组件，解包后准备模型。

模型从 Hugging Face 固定修订下载：Biomanticus/Qwen3.5-4B-heretic-gguf，修订 b63ff4662e4863cfa005c9cd8ed34b87ed44b7e1，上游文件 Qwen3.5-4B-heretic-f16_Q4_K_M.gguf，保存为 Qwen3.5-4B-heretic-Q4_K_M.gguf。SHA256为 `8485535a36c9f333574d08b650ad698ac02ec30752bd9cd87e493a3b7531bee1`。

已有模型先校验，相同则跳过下载；不匹配则下载到 `.partial`，完整校验通过再替换。下载最多两小时，有长度时显示百分比；不支持断点续传，重新下载会重新开始。网络、校验或安装失败时显示错误并允许重试；只有全部步骤成功后才从安装目录启动桌宠。

解包覆盖应用文件，已有同名模型通过校验后继续使用，设置保留。此安装流程不使用程序文件清单去清除所有旧包独有文件。安装完成创建桌面与当前用户开始菜单快捷方式。

安装程序创建启动快捷方式，不登记Windows标准卸载项，不随包提供独立标准卸载器，也不通过安装逻辑为安装目录补授普通用户写入权限。

## 本地数据与网络请求

普通运行中，屏幕截图、OCR文字、界面资料和模型生成内容在内存中用于本次请求，不写成对话历史。模型消息不包含前次交互，界面不提供与鱼鱼连续对话的输入框。

网络访问用于模型下载、天气和科技新闻。读屏资料通过127.0.0.1发送给本机推理服务，不随天气或RSS请求发送。模型下载请求使用固定公开模型地址；天气请求发送所选地区中心坐标；新闻请求获取公开RSS。

磁盘持久化包括preferences设置及其替换文件、模型文件、新闻预约日期、单实例锁及ready状态。程序异常可写入 companion-errors.log；模型子进程的标准输出和错误输出被持续读取并丢弃。

显式 --test-mode 模式每秒写 test-status.json，并读取一次性 test-command.txt 后删除命令文件。命令可打开或关闭设置、天气、吐字测试、隐藏恢复、触发自动生成、切换模拟供电、开关模型、切换可检查窗口样式、渲染窗口以及按名称播放动作。固定bubble命令只显示布局用预设文字，speech-test仍使用真实模型。

该模式render命令可生成角色布局PNG；正常启动不带该参数时不执行这些命令与诊断写入。
