# 蓝色大肥鱼 1.1.0 行为规格

## 运行平台与发行类型

程序提供 Windows x64 与 Linux x64 桌面程序。Windows 主程序为 `BigBlueFish.exe`，使用 WPF；Linux 主程序为 `BigBlueFish.Linux`，使用 Avalonia。两者使用相同的本地模型请求、语气、天气、新闻、地区数据和动画权重代码。Linux 的动画解码、OCR、供电与窗口读取采用 Linux 实现。

每个平台提供标准版和无MCP版。标准版包含可选的ACP连接、内部MCP控制服务与stdio桥接程序；无MCP版在编译时排除控制服务、工具执行器、输入对话窗口与 Agent设置页面，安装包不含 `BigBlueFish.Mcp` 和 `BigBlueFish.Control.dll`。无MCP版读取设置时强制关闭 AgentEnabled、AgentDailySpeech、PuppetMode。无MCP版的更新检查选择无MCP版安装包。

Windows 的工作目录为安装目录中的 `data` 子目录，设置、模型及缓存分别位于 `data/preferences.json`、`data/models`、`data/cache`。启动时准备数据目录，将安装根目录中的旧 models、cache、设置、模型选择及运行状态文件移动进去；目标已存在的同名文件优先保留，冲突的源文件留在原处。目录移动不复制整份模型，处理可在中断后继续，直接遇到的链接路径拒绝迁移。程序、动画、图标、ffmpeg 和推理运行时从程序自身目录加载，不依赖进程启动时的工作目录。数据目录准备失败时显示原因并退出。Linux 的程序目录为 `/opt/bigbluefish`，用户数据目录为 `$XDG_DATA_HOME/bigbluefish`，未设置 XDG_DATA_HOME 时使用 `~/.local/share/bigbluefish`；环境变量 BIGBLUEFISH_DATA 可指定数据目录。Linux 将工作目录设为数据目录，程序、动画和推理运行时从程序目录加载。

Windows 使用 `Local\BlueWhaleCompanion` 互斥量限制同一登录会话中的单实例，并持有 companion.lock。Linux 使用包含用户名的命名互斥量。第二个实例退出。主调度间隔为40毫秒；退出时关闭调度、动画、模型、MCP、输入框、设置、气泡与托盘，并保存设置。Windows 模型和动画子进程通过 Job 管理；Linux 解码、OCR和推理程序经 RunnerGuard 启动，宿主退出时收到父进程退出终止信号。

## 设置与保存

下表为 CompanionPreferences 的持久化字段。设置写入 preferences.json.tmp 后替换 preferences.json；既有文件替换时产生 preferences.json.bak。读取主文件失败时尝试 bak 文件，再失败则使用默认值。

| 字段 | 默认值 | 当前行为与取值 |
| --- | --- | --- |
| ModelEnabled | true | 启用内置本地模型；外部 MCP 原文显示不依赖此开关 |
| GpuEnabled | true | 本地推理使用 GPU；关闭后使用 CPU |
| PublicInfo | true | 获取天气和科技新闻 |
| ForegroundEnabled | true | 自主生成时读取当前前台内容 |
| StopModelOnBattery | true | 离电时取消推理并卸载本地模型 |
| HideOnFullscreen | true | 检测到外部前台全屏时自动隐藏桌宠 |
| CheckUpdatesOnStartup | true | 启动后检查新版本 |
| AgentEnabled | false | 连接本机CLI Harness；仅用户界面可修改 |
| AgentHarnessId | codex | 首选Harness的目录id；未知id在初始化连接时归到codex |
| AgentDailySpeech | false | 日常文字交给Agent，不调用本地模型 |
| PuppetMode | false | 停止自身说话与动作调度；需要AgentEnabled |
| AgentRespondToClick | false | 点击事件是否主动提交ACP轮次 |
| AgentRespondToDrag | false | 拖动结束事件是否主动提交ACP轮次 |
| WeatherRegionCode | 340104 | 天气区县；必须为内置地区数据中的区县代码 |
| Scale | 1 | 桌宠尺寸，0.5–2.0；界面以5%为步长 |
| BubbleScale | 1 | 独立文字气泡尺寸，0.5–2.0；界面以5%为步长 |
| SpeechMinMinutes | 10 | 选中说话随机区间的下限：2、3、5、10、15、20 |
| BubbleDurationIndex | 3 | 0–7分别对应5秒、10秒、15秒、30秒、1分钟、2分钟、3分钟、直到下一句 |
| AnimationIntervalSeconds | 40 | 普通动作事件等待间隔，30–300秒 |
| BreakfastHour | 8 | 早餐中心时间，0–23时 |
| LunchHour | 12 | 午餐中心时间，0–23时 |
| DinnerHour | 18 | 晚餐中心时间，0–23时 |
| LastBrushDate | null | 已执行每日刷牙的本地日期，yyyy-MM-dd |
| Left、Top | null | 已保存的位置；Windows为逻辑坐标，Linux为屏幕像素坐标 |

读取时会限制尺寸、动作间隔、餐时、气泡驻留索引等字段；无效地区归到默认区县。说话区间下限会归到支持的档位。气泡尺寸非有限值归到1。AgentEnabled 为 false 时 PuppetMode 被置为 false。

开机启动是系统设置，不保存在上述 JSON 字段中。Windows 使用当前用户 Run 键，名称为 BlueWhaleCompanion；Linux 使用当前用户配置目录的 autostart/bigbluefish.desktop。MCP 以 StartupEnabled 字段读取和修改该设置。

## 窗口、显示与用户操作

角色窗口透明、无边框、置顶，不显示任务栏按钮，不因点击角色而取得键盘输入焦点。气泡使用独立的透明置顶窗口，跟随角色移动，包含关闭按钮。设置窗口是正常可激活的桌面窗口；再次打开已有设置时恢复最小化状态并将其显示到前面。MCP 输入框是依附角色的可激活输入浮层，没有标题栏或任务栏按钮。设置窗口不会永久置顶，切到其他应用后可被正常覆盖。

位置约束使用角色的可见身体区域，而非整张透明素材的边界。基础动画画布为640×360，主要可见身体区域按 x=208–428、y=58–336 映射；桌宠大小按 Scale 缩放。恢复保存位置后，将可见身体限制到所在显示器工作区。Windows 处理显示器配置变化和 DPI 变化；Linux 在缩放、恢复显示和拖动结束时重新限制位置。

左键点击触发点击池动作。Windows 仅在 MCP 输入功能实际可用时按系统双击时间延迟单击动作，并按系统双击距离判断第二次点击，双击打开输入框时取消待执行的单击动作；其余情况单击直接执行。左键按住并移动超过拖动阈值后移动窗口；阈值以内不移动窗口，Windows 使用按 DPI 换算后的位移，Linux 使用屏幕像素位移。普通模式拖动时播放悬空片段，松开后结束拖动状态、保存位置，并恢复调度。角色透明像素不占用普通桌面点击区域；Windows 使用素材透明度命中测试，Linux 更新 X11 输入形状。

角色右键菜单提供设置、天气、吐字测试、隐藏桌宠；托盘菜单还提供显示桌宠和关闭桌宠。右键菜单在点击菜单外部区域时关闭。隐藏后可以从托盘恢复；托盘左键也可恢复显示。用户隐藏与全屏自动隐藏分别记录，全屏结束只恢复由全屏条件隐藏且没有被用户主动隐藏的桌宠。退出开始后关闭模型安装和更新窗口，取消其进行中的传输或导入；关闭流程不再接受显示、隐藏或打开设置的操作，最终清理托盘与后台资源。

Windows 每次调度依据用户隐藏标志和当前全屏条件校准窗口实际可见性，托盘菜单按实际窗口状态显示“显示桌宠”或“隐藏桌宠”。角色菜单的外部点击监听只在菜单打开期间存在，原生鼠标回调将关闭操作排入界面队列后立即放行输入；安装监听失败不禁用菜单命令。休眠时取消生成并停止模型；恢复，或调度时发现间隔超过30秒或系统时间回退超过1秒时，清除遗留的生成、天气、拖动、鼠标捕获、移动与单击等待状态，关闭旧菜单监听，使旧模型结果失效，检查托盘并重新安排模型准备和说话。已解码角色回到相应待机，关心触发与动作接管仍固定使用“待机呼吸休闲”。

Windows 托盘使用独立的隐藏原生消息窗口与安装路径对应的稳定标识；标识取程序目录规范化绝对路径转大写后的 SHA256 前16字节。图标从随程序的 BigBlueFish.ico 读取32×32尺寸，悬停文字为“蓝色大肥鱼”。注册时先请求添加，失败后尝试修改已有图标，按系统调用的实际返回值记录是否注册成功。添加失败时每3秒重试并记录一次错误及 Win32 错误码；恢复后记录恢复状态。注册成功后每30秒查询系统图标位置，图标丢失时重新注册；Explorer 通知任务栏重建时立即重新注册。隐藏角色不会移除托盘。托盘左键或双击恢复角色，右键打开同样的现代风格菜单，更新通知点击后打开更新窗口；退出时移除图标、停止重试计时并释放消息窗口、图标及菜单。

Windows 设置分为陪伴与外观、说话与天气、模型与供电，以及标准版的连接 Agent。Linux 设置分为桌宠与显示、模型与信息、动作与作息、关于与更新，以及标准版的连接 Agent。天气地区按省、市、区县三级选择。尺寸、作息、供电、联网、模型、全屏隐藏、启动更新等设置保存并生效。

MCP 修改设置不打开、关闭或激活设置窗口。窗口已经打开时在原窗口内刷新控件，保留当前页面、滚动位置、窗口位置与最小化或最大化状态；普通设置变更不抢占当前应用的输入焦点，不改变窗口置顶状态。用户显式打开设置时才执行恢复和激活。首次启用关心触发与动作接管仍显示需要用户确认的告知弹窗。

## 气泡、加载与文字显示

气泡使用乐米小奶泡体、奶油色底、角色发色的蓝色轮廓与文字，带朝向角色的小尖角。BubbleScale 调整文字、内边距、圆角及气泡整体大小，不改变角色尺寸。气泡位置限制在所在显示器工作区内，优先放在角色上方，空间不足时换到下方并限制边缘位置。

普通完整结果先按全文测量气泡，再逐字显示，避免气泡随每个字不断变宽。文字按组合字符边界推进。流式生成时，气泡跟随本地服务已经返回的文字更新。正常驻留从完整吐字结束后计算；“直到下一句”不设置自动消失时间。点击关闭按钮收起气泡。

开始本地模型说话任务后，在角色头部右上附近显示蓝色加载环。加载环旋转并改变弧长，生成结束、取消或外部原文接管时停止。天气和吐字测试也使用这一显示状态。MCP 的 say 直接进入原文逐字显示，不启动本地推理或加载动画。

## 普通模式的动画状态机

动画素材为106个透明 WebM 片段，解码为带透明度的帧后显示。正常播放以24帧/秒的片段时序推进；无打断时，在完整片段边界决定后续动作。隐藏期间暂停动画时钟和帧推进。进入新动作会取消旧解码任务。Linux 的数据读取和解码结果读取在后台进行，显示帧显式交给界面线程。

普通启动播放“女仆屈膝礼仪”，速度为1.5倍，并立即显示欢迎词：`主人早上/中午/下午/晚上好，鱼鱼给主人请安啦~`。5:00–10:59为早上，11:00–13:59为中午，14:00–17:59为下午，其余为晚上。欢迎词随启动行礼结束而收起。普通关闭时播放相同的1.5倍行礼，并显示 `主人再见~鱼鱼喜欢主人哦`，动作结束后退出。两句均不等待模型加载。

启动结束后进入待机池。每次待机片段结束重新按当前本地时间选择待机动作。到达 AnimationIntervalSeconds 指定的事件时间后，也等待当前片段结束，再从事件池选择一次；选中时安排下一次事件到期时间。因此动作事件不会因定时器到期而截断正在正常播放的片段。

移动事件包含去程、原地待机一次、返程。选取距当前位置约70×Scale的水平目的地，受可见身体工作区约束；左侧空间不足时尝试右侧。移动片段按去程方向镜像，返程方向相反。位置只在片段中间的移动阶段插值，完成返程后回到起点。Walk 使用前后各2秒的非移动段；Run 使用前1.75秒和后4.8秒的非移动段。

点击池有5个动作，按点击时的权重选择。拖动使用“被鼠标拖拽悬空反馈”的1.5–6秒区间；该区间结束后保持最后悬空姿态，直到松开鼠标。点击、拖动、外部立即动作和退出属于可打断当前片段的交互。

每天本地23点内，到达可调度片段边界时，若 LastBrushDate 不是当天日期，记录当天并播放一次“晨间刷牙”。设置窗口打开、角色被隐藏或正在拖动时，普通事件选择暂缓。工作识别上下文固定为未启用，配置中的 WorkKind/WorkWeight 不参与自主选择。

## 权重、餐时、季节与节日

随机池分为 Idle、Event、Click；Greeting、Drag、Daily 为直接状态动作，Disabled 不参加自主随机。随机选择只在指定池内进行，排除有效权重为0的条目；某动作的条件概率为其有效权重除以该池所有有效权重之和。

权重按以下顺序计算：先判断禁用、夜间限定、季节限定及移动时间门槛，再取基础 Weight；夏季或冬季可覆盖基础权重；8:00–10:59可使用 MorningWeight；随后计算节日权重，再加餐时 MealBoost。工作识别启用时才可能使用工作权重，本版本普通调度不启用该识别。最终权重不低于0。

夜间为23:00–次日7:59。春季为3–5月、夏季为6–8月、秋季为9–11月、冬季为12–2月。移动动作仅在每小时第5–54分钟且小时奇偶性符合 HourParity 时进入事件池。

餐时使用设置中的整点，前后各60分钟内生效，跨午夜按一天的循环距离计算。Breakfast、Lunch、Dinner 分别对应三餐；Any 匹配任意餐时。MealBoost 是增加量，不是总权重。

节日距离以本地日历日期计算，寻找上一年、当年、下一年中最近的对应日期。Triangle 在 RadiusDays 内把当前权重向 FestivalWeight 线性推近：`W += (FestivalWeight-W) × max(0,1-日期距离/RadiusDays)`。非 Triangle 规则在半径内直接使用 FestivalWeight；半径外保留基础或季节权重，且该条目的餐时加权不生效。

固定公历节日包括2月14日、5月20日、10月31日、12月25日。农历节日包括春节、元宵、端午、七夕、中秋、腊八，使用 ChineseLunisolarCalendar 并处理闰月；不在其支持日期范围内的日期不生成对应农历节日候选。

## 自主说话的节奏与本地请求

自动说话首次到期为启动后45秒。之后从所选区间均匀抽取下一次等待时间：2–3、3–5、5–8、10–16、15–23或20–30分钟。到期时要求角色可见、未退出、未处于关心触发与动作接管、未打开设置或模型安装窗口。没有排队原文且未开启Agent日常接管时，还要求启用模型、模型可用、供电允许、没有其他本地生成或天气任务占用。Agent日常接管沿用同一计时、可见性、设置窗口和空闲门槛，到期后发送daily_care并安排下一次时间，不检查本地模型可用性。吐字测试按当前吐字编写者调用真实本地模型或发送Agent请求。

普通自动说话要求系统键鼠空闲8–600秒；不满足时把下次检查推迟30秒。吐字测试不要求该空闲区间，且设置窗口打开时也能触发。使用本地模型时，测试和普通倒计时通过同一个本地请求入口生成、显示；使用Agent编写时，手动测试发送speech_test事件。不会用固定测试台词代替生成结果，也不会因未能读屏而主动显示读屏错误句。

本地请求正在预加载或被天气任务占用时，吐字测试等待该任务，最长等待100秒，而非直接丢弃点击。模型生成前记录请求版本；取消、隐藏、供电变化、外部原文等会使旧请求失效，迟到的流式片段或最终结果不能覆盖新内容。

本地模型通过127.0.0.1的临时端口访问随包 llama-server。服务使用单并行槽、8192上下文、4个CPU线程、batch 2048、Flash Attention off；reasoning 为 off，生成按流式返回。启用 GPU 时，先通过运行时的 `--list-devices` 获取当前设备可用内存，探测最长10秒；以报告设备中最小的可用内存作为缓冲选择依据：至少8192 MiB采用ubatch2048，至少4096 MiB采用ubatch512，其余采用ubatch128。三档fit-target分别为1024、768、384 MiB。GPU层数使用auto并开启fit，实际权重分配由llama.cpp根据可用设备内存决定。GPU启动不指定device、main-gpu、split-mode或tensor-split；随包运行时的默认设备逻辑优先使用独显，没有独显时使用核显，保留其自动层分配与显存适配。CPU模式使用ngl0、ubatch512、fit off、device none。普通说话温度为0.65，新闻为0.35；普通、天气和新闻的输出预算分别为180、220和160 token。

本地请求显式启用cache_prompt，运行时内存提示缓存上限为512 MiB。普通说话的固定系统说明放在随机语气提示之前，本轮读屏材料仍独立放在user消息中。模型加载就绪前，通过运行时自身的聊天模板格式化固定说明，只为这段固定前缀执行一次不生成回复的预填充，为后续语气轮换与读屏请求建立可恢复的前缀检查点；该步骤最多等待8秒，接口或模板不适用时继续普通生成。前缀预填充不含读屏资料、不显示气泡，也不写缓存文件。每次说话仍只提交当前system和user两条消息，不附加历史对话。

关闭 GPU 设置时直接使用 CPU。启用 GPU 但设备探测失败、超时或未返回可解析的设备内存时使用 CPU 兼容模式。GPU 加载阶段发生 IOException 或超时，包括没有错误文本、只有退出码的进程崩溃时，终止和释放失败进程，再尝试一次 CPU 兼容启动；用户取消不走该重试。CPU 兼容模式就绪后复用当前进程，状态文字附“CPU兼容模式”；用户主动关闭 GPU 时不附该标记。后续重新启动模型时重新探测设备。Windows和Linux的模型设置页每秒刷新“推理设备”，依据当前runner实际加载的非零模型缓冲区显示GPU名称和运行时设备编号，可显示多张卡；仅检测到设备不算实际使用，只有CPU模型缓冲区时显示CPU，未取得分配信息时明确显示尚未确认。模型停止后显示未运行。设备事实从启动期间的INFO输出在内存中提取，不保存完整运行输出；退出的旧进程不能更新新进程的设备状态。启动失败保留可用的错误原因或十六进制进程退出码，不把失败进程继续当作可用模型。

复用已驻留模型前，以最多3秒的健康请求确认服务仍可用；失败后清理旧进程并重新启动。每次启动等待模型健康接口的期限为60秒，每500毫秒检查一次，固定前缀预填充也受该期限约束。后台预加载任务总取消期限为90秒；后台预加载失败后，界面调度的下次预加载尝试至少等待2分钟，用户主动请求仍通过普通模型入口处理。本机 HTTP 请求关闭代理，单次 HTTP 请求超时为100秒。

消息使用标准 system/user 分层：system 包含鲸鱼娘的语气、可迁移的性格演示和表达要求；user 包含本轮时间、前台材料与可用的公共信息。请求不拼接上一轮历史。普通吐字顺着眼前内容组织短小、活泼、亲近的反应；用户填写的演示用于迁移语气，不作为场景与答案的固定映射。新闻使用独立的新闻说明提示词。

本地服务就绪状态会经过健康检查。启动失败、健康异常、请求失败和取消会使已失效的 runner 引用被清理，相应子进程终止，后续请求可以重新启动。允许供电且启用模型、模型已就绪但进程尚未启动时，界面调度可提前预加载。离电暂停策略会取消本地任务并将模型移出内存；手动天气或测试在此条件下显示固定提示：`主人，当前设置为笔记本离电暂停模型，可以在设置里调节哦。`

停止模型先移除当前进程引用并请求终止，再异步等待最多5秒并释放进程对象，不在界面线程同步等待退出。加载取消后、预填充完成前后检查取消标志与进程身份。流式文字从工作线程异步排入界面队列，并再次检查当前请求版本；已经隐藏、取消、恢复会话或被新请求替换的旧片段不显示。

## 前台内容与截图

Windows 普通 OCR 读屏沿用实际前台窗口解析规则：排除自身和不可见、最小化等无效窗口；自身菜单或设置占前台时，可使用仍有效的最近外部窗口。桌面 Shell 与文件资源管理器应用窗口分别识别，已经最小化的旧外部窗口不能作为有效目标继续读取。

截图使用物理像素 DPI 上下文，目标为选定的可见窗口或桌面所在区域，先尝试窗口渲染，再使用可用的屏幕复制路径。OCR 使用 Windows.Media.Ocr，按文字位置组织界面区域并保留正文线索。桌面输入表达壁纸与快捷方式场景；普通应用输入保留应用名称、窗口标题及按空间整理的 OCR 正文。请求材料置于资料分隔区域中。

Windows OCR 优先选择可用的中文识别语言，其次英文，再选择其他可用识别语言。识别图像最长边限制为2560像素与 OCR 引擎允许的最大尺寸中的较小者，保持宽高比缩放。文字行按位置重组：行中心高度差容差为较小行高的0.48倍，相邻文字块的水平间隔门槛为40像素与行高2.3倍中的较大者。

界面文字分为顶部、左侧、正文、右侧和底部五区。顶部占图像高度前12%，底部占最后11%；中间区域中，文字块右边缘位于宽度27%以内的归左侧，左边缘超过宽度80%的归右侧，其余归正文。五区文字预算分别为700、650、3000、500、650字符；超出预算的区域保留前40%与后60%的内容，按空间顺序提供给模型。Linux Tesseract 的文字块也通过同一个版面整理器组织。

Linux X11 使用 _NET_ACTIVE_WINDOW、可见状态、最小化状态、窗口 PID 与窗口类型解析前台，排除自身；窗口类型为 DESKTOP 的窗口与根窗口视为桌面。普通应用截图读取 XComposite 背景图像，重挂接窗口时定位其顶层框架并裁到目标客户区域，以免混入顶层桌宠与气泡。全屏截图读取整个 X11 根屏幕。Tesseract 使用 chi_sim+eng，输出带坐标的 TSV，再复用空间分区整理逻辑。

Linux Wayland 的截图通过桌面 Screenshot Portal 请求授权。全屏请求使用屏幕目标；前台请求需要门户提供版本3及 Active Window 目标，否则返回不能执行该捕获的错误，不拿一个 XWayland 旧窗口代替。门户返回本机图像 URI 后读取并删除本次图像文件，随后在内存中编码。前台身份在此路径使用“当前桌面授权的前台窗口”。X11 全屏检测和键鼠空闲检测分别使用窗口状态与 XScreenSaver 接口。

MCP 的 capture_foreground 显式调用上述前台选择与截图路径；capture_screen 显式获取整个虚拟桌面，Windows 包含所有显示器。两者返回 PNG 图像内容和目标、尺寸、时间等元数据。max_dimension 默认分别为2560和4096，可设为256–16384；保持长宽比缩小，不主动放大。普通内置读屏开关不阻止这些显式 MCP 截图命令。

## 天气与科技新闻

天气按用户选择区县的中心坐标请求 Open-Meteo。资料包括当前温度、体感、湿度、天气码、风速以及当天最低/最高温与降水概率。缓存按地区保存于 cache/weather.json。普通调度触发后台刷新，同一区县两次刷新尝试至少相隔1小时；有效缓存的获取时间与观测时间都不得在未来，且两者距离当前均不超过6小时。

天气播报优先使用有效缓存。没有有效缓存时等待本次后台更新，仍没有资料则不使用陈旧天气生成。关闭 PublicInfo 不主动更新公共资料。地区变更会使本地请求材料和下一次天气选择使用新地区。

开启公共信息的普通生成有3%概率尝试新闻路径。RSS 来源为 IT之家，保留不晚于当前、48小时以内、有标题的条目，按标题去重，最多30条。标题与摘要会清除HTML并限制长度；新闻资料按内存有效期刷新。同一进程记录上次选中的标题以避免紧接着重复同一条。

新闻提示词要求用“主人”称呼、准确描述一条新闻，再接一小句感受或关切，期望30–60字、最多80字。新闻输出使用独立预算和整理路径；不要求照普通撒娇语气演示扩写。没有可用新闻时回到当前场景的普通生成。RSS 成功获取后内存有效期为45分钟，失败后保留仍在48小时内的已有条目，并等待2分钟再尝试。

本地模型输出通用清理会去掉完整的 think 段；出现未闭合 think 段时暂不显示。空白归并、去掉首尾引号；没有字母或数字，或同一字符连续重复至少9次时丢弃。少于100个 Unicode 字符的结果原样保留；更长结果取前98个字符，在至少第15字符之后找到句末标点则在那里结束，否则加省略号。MCP 原文显示不经过这段模型输出清理。

## ACP连接、技能与会话

标准版设置有“连接 Agent”页面。“连接本机兼容的 CLI Harness”默认关闭，开启前异步确认读屏、输入和交互内容将交给所选Agent，可能由其发送给所配置模型服务。取消保持关闭。开启后显示Harness下拉列表、重新检测、安装与登录说明、状态、重新连接、开始新对话、取消当前请求、人设编辑、Agent接管日常吐字和关心触发与动作接管。没有独立的双击对话开关或允许唤醒开关。日常关心的两个开关分别显示为“把日常关心的吐字交给 Agent”（AgentDailySpeech）和“把日常关心的触发和日常的动作切换逻辑交给 Agent”（PuppetMode），前者选择话语的编写者，后者选择关心时机及动作的安排者。

目录包含Claude、Codex、Gemini、DeepSeek Harness、Kimi、Qwen、Antigravity、Copilot、Cursor、OpenCode、Cline、CodeBuddy、Qoder、TRAE、Kiro、Pi、Devin、Grok、Hermes、OpenClaw、MiniMax共21项。原生命令和适配器启动方式见[ACP连接参考](ACP.md)。检测使用PATH；Windows合并当前进程、用户和系统PATH，按exe、cmd、bat、ps1及无扩展名顺序寻找。下拉列表将检测到的项目放在前面，未检测到的标明状态。检测不启动全部Agent。

选定的CLI在后台自有进程中运行，使用UTF-8逐行JSON-RPC ACP v1。鱼鱼声明不提供文件读写与终端回调，Agent使用自身工具；权限请求返回其提供的选项，未知客户端方法返回Method not found。鱼鱼自己的可识别工具请求按连接授权处理，其他请求通过正常窗口等待用户选择。普通Agent输出和历史重放不显示为气泡。Windows自有进程加入退出时清理的Job，正常关闭时终止所启动的进程树。

Claude、Codex、Pi的ACP适配器优先从PATH寻找，否则在data/agent/adapters内按固定npm版本安装，使用官方registry与独立缓存。需要Node.js/npm时显示缺少组件的原因。Codex适配器通过CODEX_PATH指定发现的Codex程序。Antigravity优先使用PATH中带配套localharness_external的agy_acp_server，否则在agent/adapters/antigravity准备Google官方组件，同时提取同一发布包的ACP程序和配套运行程序，校验压缩包SHA256并沿用发布参数。子进程通过ANTIGRAVITY_HARNESS_PATH定位配套程序。已下载的Antigravity组件计入检测；尚未下载时可在连接时准备。鱼鱼不升级或卸载原有CLI。

初始化保存Agent公布的认证方式；认证错误中附带的authMethods可更新此次选择。收到认证要求后展示可用登录方式，协议认证发送authenticate及methodId，成功后重试原会话请求一次。交互终端可用时声明auth.terminal支持：Windows支持可直接启动的程序入口，Linux使用gnome-terminal、konsole或xterm。终端登录使用相同程序、工作区及环境，追加所选方法的args并应用env，展示参数后由用户选择；旧_meta.terminal-auth格式使用其登录参数替换常规ACP参数，忽略其中的command。终端成功退出后重新初始化ACP并继续原会话请求，非零退出显示失败。认证最长等待5分钟，可取消；已有账号凭据的复用和浏览器登录由Agent官方组件处理。取消选择停止自动重连，原会话记录保留。没有公布认证方式时显示错误及安装登录说明入口。

生成请求在执行工具和发言前返回认证错误时，关闭旧连接并恢复会话，认证后重试该轮一次。已报告工具调用或已发言的轮次不自动重发。结构化authentication_failed错误按认证错误处理，保留原会话绑定。

所有Harness共用当前选定的持久工作区。默认路径为系统用户文档目录内的“蓝色大肥鱼工作区”；系统未提供文档路径时使用用户主目录下的Documents。agent/workspace-state.json保存当前路径及最近30个路径。Agent进程和ACP会话的cwd均为当前工作区，桌宠自身的数据工作目录仍为data。项目可在工作区中由用户和Agent组织；新建对话、项目或切换Harness保持当前工作区。

设置页提供新建工作区、打开工作区、查看文件夹、清空工作区。新建输入目录名并选择存放位置，目录已存在时要求打开或更名；打开选择已有目录并切换。查看文件夹使用系统文件管理器。切换会取消旧轮次与排队请求，关闭自有连接，后台准备目标目录及技能，并恢复对应会话。清空显示完整路径并确认，删除目录内全部文件及子目录，重置该工作区所有Harness会话绑定与其预约，随后重新准备默认技能、人设及新会话。保留工作区目录和其他工作区文件。系统根目录、用户主目录、文档根目录、Windows与Program Files目录、程序目录、控制数据本身及其祖先目录拒绝清空；当前目标已改变或目标为目录链接也拒绝。子目录链接的外部目标保留。

工作区的Harness技能目录内安装big-blue-fish/SKILL.md和persona.md。默认操作技能按内容哈希记录到.fish-skill.sha256，未被用户修改的默认技能随程序更新；已修改的技能保留。已有人设文件保留，各产品使用各自发现技能的目录。默认人设来自随包嵌入的人设卡，编辑或清空后保存。新对话首次事件和人设内容变化后，消息指定技能名、文件路径及重新读取当前人设的要求；文件无法读取时可调用get_operation_guide。消息包含软件来源、事件类型、本地时间、当前模式与事件正文。人物说明不会整份重复附在每一轮。

agent/sessions/工作区路径SHA256/Harness编号.json保存会话编号、程序路径和工作目录；Windows路径按不区分大小写的形式计算绑定。初次通过session/new建立会话，同时传入内部MCP配置。重新连接时，程序路径和工作目录一致且对方支持恢复，优先session/resume，否则session/load。会话或资源不存在、会话已过期删除时自动新建并保存新编号；登录等其他错误保留原记录。未提供恢复能力的Agent进程重启后使用新会话。开始新对话清除该Harness预约、建立并保存新的会话编号，保留工作区文件。原会话的保存由Agent处理。

设置的模型与权限区域显示当前Agent报告的配置项，名称、分组、说明和当前值取自Agent。configOptions优先于旧模式字段，select绘制下拉框，boolean绘制复选框，未知控件类型跳过。初始化声明session.configOptions.boolean支持。修改使用session/set_config_option；成功响应及config_option_update包含的完整选项替换当前列表，依照协议到达顺序应用。旧models和modes状态分别使用session/set_model及session/set_mode，Agent返回Method not found时该项转为只读。可选值只能来自Agent报告；未提供配置能力时显示由Harness配置。正在生成、修改配置或切换工作区时选择器禁用。权限／工作模式按Harness执行，单项操作的批准窗口继续独立处理。

请求等待队列上限32，连接、重连、日常关心、预约到期和开始关心事件分别合并。用户文字队列满时不清空输入。ACP初始化最长45秒，普通控制请求60秒，模型轮次5分钟。取消或模型轮次超时发送session/cancel并关闭该自有连接，后续恢复会话。登录错误停止自动重连，其他请求失败两分钟后可重试。实际断开时清除就绪状态。结束轮次必须返回stopReason；没有调用说话工具时状态显示本轮未调用说话工具。

## 内部MCP工具

连接开启后，在用户范围命名管道上创建内部控制服务。管道名包含用户目录哈希和本次进程的随机标识。会话配置包含随包BigBlueFish.Mcp桥接程序的绝对路径及--pipe参数；界面不提供复制外部MCP配置。桥接程序等待管道连接5秒，失败向stderr输出原因；不自行启动桌宠。关闭连接会关闭Agent、内部服务、输入框和确认窗口，清除外部队列并退出关心触发与动作接管。

内部MCP支持2025-03-26或2025-11-25初始化协商、ping、工具、日志、资源读取订阅与请求取消。收到notifications/initialized后计为工具连接；每客户端输出队列最多128条，输入单条最多1Mi字符。截图通过image content返回。服务不发送sampling请求。

| say | 按原文进入气泡逐字显示，取消旧本地生成，不改写文本 |
| say_next | 保存到下次符合普通日常节奏时显示，新的覆盖旧的 |
| request_local_speech | Agent请求真实本地模型按当前情境生成日常关心，无需传入文字 |
| get_operation_guide | 返回安装的操作技能全文和当前人设 |
| get_wakeups | 返回当前Harness会话的预约和启用状态 |
| schedule_wakeup | 创建或修改关心预约，可指定重复周期 |
| cancel_wakeup | 取消当前Harness会话中指定id的预约 |

AgentEnabled与AgentHarnessId只能由用户选择；Agent可修改PuppetMode、AgentDailySpeech、AgentRespondToClick/Drag及其他schema中的普通设置。PuppetMode由false改true仍要用户确认。text最多4000个UTF-16单元且非空白；动作名必须精确匹配，最多200字符。原文不经过本地模型输出整理。工具成功表示提交操作，不等同显示或播放完成。Windows通过界面调度器执行控制，更新设置不打开或激活设置窗口；Linux应用设置时停止当前本地模型并重排计时。

## 日常接管与预约

Agent日常接管关闭时，普通模式沿用内置模型设置。只开启Agent日常接管时，鱼鱼按原有计时和空闲门槛发送daily_care；Agent通过say返回自己编拟的话。后台本地模型预加载在Agent日常接管开启时暂停。手动天气和吐字测试按当前吐字编写者选择本地模型或Agent，不受日常触发接管影响；Agent天气请求附带所选地区最近六小时内的天气资料。

关心触发与动作接管开启时发送start_care，Agent可调用schedule_wakeup安排下一次或重复关心。预约按Harness及会话隔离，保存到agent/wakeups.json，最多32项。delay_seconds和可选repeat_seconds为30–604800秒，purpose为1–1000字符，可提供id修改已有预约。预约工具在关心触发与动作接管开启、会话已连接时接受创建。AgentDailySpeech=true时预约到期发送wakeup，由Agent编写；false时预约到期直接调用真实本地模型，沿用读屏、生成和逐字显示流程。request_local_speech可立即请求同一条本地生成流程，需要Agent连接开启、AgentDailySpeech=false、本地模型可用及允许的供电状态；隐藏或已有本地吐字任务时返回错误。

鱼鱼每次调度检查预约；角色隐藏、全屏隐藏、拖动、退出或未连接时不投递。到期预约合并为一次处理；请求提交前从一次性预约中移除，重复预约从本次投递时间加周期安排下一次。休眠恢复不逐次补发错过的周期。正在处理轮次时预约事件等待并合并。切换吐字编写者保留预约并通知Agent检查安排；关闭连接或离开关心触发与动作接管时清除当前Harness预约。

## 关心触发与动作接管

模式生效条件为 AgentEnabled 与 PuppetMode 同时开启。用户通过界面或 MCP 开启前都要看到并确认告知：外部 Agent 关闭或断开后，桌宠不会自动恢复自身功能，需关闭关心触发与动作接管才能恢复。

生效后停止鱼鱼自身的说话计时和启动、关闭问候。角色菜单和托盘菜单中的天气、吐字测试保持可点击：AgentDailySpeech=false时手动进入真实本地生成，true时通过ACP发送speech_test或weather_request事件，请Agent通过say回复。手动请求不要求日常空闲时间，设置窗口打开时仍可执行。说话间隔选择器置灰并说明由Agent安排时机；关闭接管触发后恢复可调。AgentDailySpeech=false时本地模型按模型开关和供电设置自动预加载，供手动请求、Agent预约或工具请求生成；true时本地模型不自动加载。设置窗口保持打开不阻止本地预加载。模型状态页说明当前触发者与吐字编写者。

进入模式后立即播放“待机呼吸休闲”，此后永远循环这个单一动作；日期、餐时、节日、点击池和普通事件倒计时都不切换动作。鼠标仍可物理拖动角色并发送交互事件，但不自动播放悬空动作，松手也不截断外部正在播放的动作。

外部指定的动作按立即或排队命令播放。片段结束后优先播放下一个已排队外部动作；没有队列时回到“待机呼吸休闲”循环。外部 say 可显示其指定文字。外部断开不修改 PuppetMode，不恢复随机动画或自主说话。

显式关闭模式后重新安排普通说话与事件等待时间，恢复待机随机选择和按供电策略预加载。关闭应用时，模式内直接退出，不插入自动行礼或告别文字。

## 交互推送与双击输入

每次左键或右键点击、拖动开始和拖动结束形成交互事件，包含递增 sequence、UTC time、kind 与 detail。点击附按钮信息；拖动附位置及结束是否取消。事件通过 MCP notifications/message 发送，level=info，logger=bigbluefish.interaction；客户端可用 logging/setLevel 设置接收日志门槛。

最近128条事件保存在控制服务内存中。资源 URI 为 bigbluefish://interactions，可读取该队列，也可订阅其更新通知。MCP 服务关闭后，该服务实例和内存事件记录释放。多客户端各自接收推送。

事件序号在服务实例内递增，日志推送与资源读取是同一事件的不同获取方式。订阅只通知资源更新，客户端自行读取数组；读取不清空队列。客户端需按本次服务实例与sequence去重，旧事件超过128条会覆盖。日志门槛高于info时不发送info交互日志，资源订阅仍可接收更新。

文字输入通过ACP向当前鱼鱼专用对话提交user_message，固定开启双击输入。AgentRespondToClick和AgentRespondToDrag默认关闭，开启对应字段后，点击或拖动结束另外发起一轮ACP请求；两项由Agent修改，设置详情只显示状态。资源仍保留全部交互事件。

AgentEnabled开启后双击角色可打开输入框。连接尚未就绪时显示当前连接状态并禁用发送；不要求先打开独立聊天开关。

输入框以354×120逻辑单位的紧凑浮层贴在角色可见身体一侧，优先左侧，空间不足时改为右侧；底部与角色可见身体底部对齐，并限制在当前显示器工作区内。浮层使用奶油底色、发色蓝边框和圆角，不显示标题栏与任务栏按钮，不提供独立移动或缩放。空输入框显示灰色提示“通过鱼鱼和已连接的Agent说话”，输入文字后提示消失。支持多行、最多4000个UTF-16单元，普通 Enter 换行；点击发送或 Ctrl+Enter 提交，Esc或右上角关闭按钮收起输入框。提交原文以user_message进入ACP请求队列，同时写入内部交互资源；仅在实际连接且成功入队后清空输入并恢复灰字。Agent通过say等工具回复。

重复双击激活已经打开的输入框，不重复创建。输入框跟随角色位置与尺寸变化，隐藏角色时同步隐藏并保留草稿，恢复角色时在新位置显示，不自动抢焦点；只有用户显式打开或点击输入框时获取键盘焦点。桌宠本体保持置顶且不主动取得输入焦点。客户端全部断开后，输入框中的发送按钮置灰，保留未发送草稿；重新连接后恢复可发送状态。发送动作本身再次检查连接和开关。关闭Agent连接或退出应用会关闭输入框。Linux 除平台双击计数外，还识别500毫秒内、屏幕位置差合计不超过8像素的第二次点击；拖动会清除该连续点击状态。

## 模型安装、更新与卸载

模型管理提供 Hugging Face（推荐）、国内源（稳定）、手动安装与无模型运行。Hugging Face 为固定修订的 Qwen3.5-4B-heretic Q4_K_M；国内源为固定修订的原版 Qwen3.5-4B Q4_K_M。自动下载会检查固定 SHA256，使用未完成文件继续下载；下载连接无响应45秒时报告错误。下载失败后可以重试、转手动或无模型运行。

模型下载过程中提供“放弃并转为手动安装”。点击后弹出“放弃自动安装会删除已下载的部分模型，您可以手动安装模型。”，提供“放弃自动安装”和“不要放弃”两个按钮。选择“不要放弃”或关闭确认窗口时继续当前下载；确认放弃后取消传输，等待文件释放，删除当前来源对应的 `.partial` 未完成文件，保留正式模型及其他来源的未完成文件，随后保持模型安装窗口打开、进入手动安装并打开当前来源的网页。清理失败时显示错误，不进入手动安装；关闭应用或模型窗口时不再打开手动安装页面。Windows 手动安装区显示 models 绝对路径，Linux 进入手动文件选择流程。

关闭安装窗口、网络读取失败、连接在预期长度前提前结束或应用进程退出后，后续下载按实际保留的文件长度发送 Range 请求。服务器返回206且 Content-Range 起点与已有长度一致时追加，否则从头写入。服务器返回416时，校验已有未完成文件：完整且哈希正确则改名为正式模型，否则删除未完成文件并提示重试。普通完整下载结束后也进行 SHA256 校验，通过后替换正式文件，校验不符时清理本次未完成文件。自动创建的 HTTP 客户端连接超时为20秒、请求总超时为2小时，单次读取45秒没有数据时报告错误。重新打开模型安装界面时，若国内源有最近修改的未完成文件，选择该源；否则默认 Hugging Face。下载进度、源选择与手动导入在单次传输期间互斥。

应用内的模型安装与 Windows 更新窗口按普通非模态窗口显示，重复打开时激活已有窗口。打开 Windows 模型安装窗口时先停止当前本地模型，设置窗口可见时将其作为所有者。正常关闭模型窗口后刷新模型可用性、允许重新预加载，并把下一次自动说话安排为20秒后。关闭模型安装窗口会先取消进行中的下载或导入，完成取消收尾后关闭；退出桌宠不等待用户操作这些窗口，也不因窗口关闭重新预加载模型。桌宠开始退出及最终清理时均请求相关窗口关闭，已开始退出后不再接受恢复显示、隐藏或打开设置的操作。

手动安装提示当前数据/安装目录下 models 的绝对路径，可打开模型来源网页并选择本机 GGUF。文件先检查 GGUF 结构，未知 SHA256 允许在用户确认“这不是本软件期待的模型，您可以尝试使用，但稳定性无法保证”后使用。复制通过临时 importing 文件进行，完整校验后替换，并写 model-selection.json。源文件已经位于目标位置时不重复复制；Windows 路径比较忽略大小写，Linux 路径比较区分大小写。

选择模型以 model-selection.json 为准；没有选择记录时尝试已知模型文件名。明确选择 none 时不自动捡起目录中的其他文件。没有模型时，启动、退出问候及动画照常，内置模型不生成；设置提供安装模型入口。MCP 原文显示和外部动作不依赖模型。

Windows 安装器自包含本地 .NET 运行环境、动画解码与推理组件，默认安装到 Program Files 中自身的蓝色大肥鱼子目录。安装器将运行数据整理到安装目录下 data 子目录，为 data 授予内置 Users 组可继承的完全控制，并为 data 内具有受保护 ACL 的目录及文件补充相同权限；遍历跳过链接。不修改安装根目录和 Program Files 父目录的 ACL，不回收旧安装根目录已经存在的授权。创建快捷方式、开始菜单、App Paths 和 Windows 卸载登记。解包按清单覆盖程序并移除不再分发的程序文件，保留 data 及旧模型、设置和缓存。清单记录 Version、InputMode、Files、Edition；切换到无MCP版会移除标准版 MCP 程序文件。

Windows 桌面、开始菜单应用入口和卸载入口的快捷方式均引用安装目录中的独立 BigBlueFish.ico，图标路径带引号及索引0；各快捷方式的工作目录为安装目录，主程序启动时切换到 data。设置窗口显式使用BigBlueFish.ico作为窗口与任务栏图标，保持普通可激活窗口和非置顶策略。

Windows 独立 Uninstall.exe 打开卸载界面，“保留模型和设置”默认不勾选。卸载工作进程从安装目录外运行，停止属于本目录的进程、删除清单文件并清理本安装的启动项、快捷方式及系统登记。勾选保留时留下模型、设置和缓存；默认清理本应用数据，仍有未列入删除清单的外部文件时保留非空目录。

Windows 更新检查读取项目最新正式 Release，按标准版/无MCP版选择对应 OCR 安装器及校验信息，下载并核验后直接启动更新安装器。安装器等待当前应用退出并在同目录更新，复用模型和用户设置。取消或失败不会当作更新成功。

Windows 更新窗口显示该 Release 的发布说明；说明按 GitHub 风格 Markdown 渲染标题、段落、粗体、斜体、删除线、行内与围栏代码、链接、引用、无序/有序/任务列表和分隔线。链接只接受 HTTP、HTTPS 与 mailto，其他目标按原文显示；没有说明时显示占位文案。

Linux 通过标准或无MCP版 .deb 安装到 /opt/bigbluefish，注册 bigbluefish 启动命令、图标与桌面菜单。依赖由系统包管理器提供，.NET 随包。两种包声明互斥并替换同一程序目录；用户数据在个人目录中，系统卸载不删除该个人目录。Linux 更新检查选择对应 .deb，核验下载后通过 pkexec 和 apt-get 安装，成功后等待旧进程结束再启动新进程。

## 版本与构建工具行为

根目录 Version.props 指定产品版本1.1.0，文件版本与程序集版本为1.1.0.0；Windows、Linux、MCP桥接程序、安装器与卸载器从同一版本属性生成。CompanionEdition 为 Standard 或 Safe，Safe 对应无MCP版；当前标准发行采用 OCR 读屏。

PowerShell 构建与测试脚本以带 BOM 的 UTF-8 保存，兼容 Windows PowerShell 对中文脚本的读取。PowerShellEncodingVerification.ps1 枚举 Git 已跟踪及未忽略的 .ps1 文件，检查 UTF-8 BOM 并通过 PowerShell 语法解析器读取；检查失败抛出错误。code/test.ps1 在其他检查前调用此脚本。

Windows 安装器构建显式接收已核对的推理运行时目录，以自包含方式发布桌宠、标准版 MCP 桥接程序与独立卸载器，附加动画解码组件、Visual C++运行库与许可文件，再生成安装器及 SHA256文件。本次使用的 payload目录、setup-stub目录、uninstaller目录、中间压缩文件或目标安装器已存在时报告错误，不覆盖这些已有构建产物。Linux 构建按发行类型发布自包含程序，加入推理运行时、RunnerGuard、PortalCapture与许可，生成对应的 .deb 与 SHA256文件。

## 持久化、网络与诊断

内置本地模型不建立聊天历史。ACP会话历史由对应Agent按其配置管理。前台截图、OCR文字、本次模型资料、生成内容及 MCP 交互队列主要在内存中使用。模型请求发送到本机回环地址；天气、RSS、模型下载和版本检查请求发送给各自的公开服务，不把内置读屏资料附在这些请求中。Agent截图、输入与事件按工具命令或消息交给所选Harness，资料的后续处理由其配置决定。鱼鱼另保存Agent技能、人设、会话编号、预约及适配器组件；不将普通ACP输出自动落盘为聊天历史。

本机持久化包括 preferences 及其替换文件、model-selection、模型、天气缓存、更新下载与事务数据、安装卸载记录、单实例和就绪状态、每日刷牙日期等。程序异常可以写 companion-errors.log。模型进程使用 log-verbosity 4 输出启动信息；程序持续读取标准输出和标准错误，在加载就绪前提取实际设备与模型缓冲分配信息，标准错误同时仅在内存保留最后8行、每行最多500字符，用于解释加载失败。加载就绪后继续消费输出，不再更新启动设备记录或错误队列。Wayland 门户图像文件由桌面服务产生，读取后删除。

显式 --test-mode 会启用状态文件和一次性 test-command.txt。状态包含当前版本、动作、播放阶段、帧、窗口、文字、设置及模型状态；测试命令可以打开设置、调用真实天气或吐字测试、隐藏恢复、播放动作或显示布局文字，并将窗口渲染为 PNG。固定 bubble 命令是布局辅助，不代替真实吐字测试。

该模式下，Windows 本地请求可写 OCR 和 model-request 等诊断资料；Linux 可按 ocr、render、render-settings、render-input 命令写诊断或窗口图像，并记录帧读取与显示耗时。常规启动不读取这些测试命令，不产生本轮读屏或生成内容的诊断文件。
