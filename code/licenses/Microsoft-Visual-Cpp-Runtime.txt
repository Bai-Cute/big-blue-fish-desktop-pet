The Windows release includes unmodified x64 CRT redistributable files from the
Microsoft Visual Studio Community VC/Redist/MSVC directory. They are deployed
alongside the llama.cpp executable. File versions and SHA-256 values are recorded
in runtime/visual-cpp-runtime.json in the installed application.
